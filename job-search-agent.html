OPENAI WORK / REUSABLE WORKFLOW

Job Search
Agent

A reusable prompt and setup guide for a structured job-search workflow in ChatGPT Work: source roles, score fit, prepare tailored materials, track outcomes, and use connected Gmail for application follow-up.

Use it responsibly. This workflow never invents qualifications or answers. It pauses for CAPTCHA, MFA, required legal attestations, account/password creation, sensitive fields, and final submission unless the user explicitly reviews and approves.

Setup in ChatGPT

  1. Open ChatGPT Work. Start a new Work chat on chatgpt.com. Scheduled tasks can use connected plugins, including Gmail, when available.
  2. Connect the needed apps. In Plugins, connect Gmail and a job-search source you trust. Select the correct Gmail account and approve only the access you intend to use.
  3. Attach your own materials. Add your master résumé, résumé template, and a private profile sheet with your own contact information, work authorization, locations, and salary preferences.
  4. Paste the prompt below. Replace bracketed placeholders with your criteria. Run it once manually first and inspect the results.
  5. Create the weekday schedule. In the same chat, ask: “Schedule this task every weekday at 9:00 AM in my local time. On each run, use connected job sources and Gmail, return the tracker and a concise summary, and stop at any item marked NEEDS REVIEW.”
  6. Review the first runs. Check the Scheduled tab, refine the scoring or location filters, and pause the task when you no longer want it to run.

OpenAI recommends testing a scheduled-task prompt in a regular chat before scheduling it. Gmail-enabled scheduled tasks require the connector to be available and authorized for the user’s account.

Copy the prompt

OBJECTIVE
Act as my Job Search and Application Workflow Agent. Every weekday, find and evaluate high-fit U.S. jobs using my attached master résumé, résumé template, and private profile sheet. Optimize for quality and fit, not application volume.

TARGET ROLES
Search recent roles: [TARGET ROLES]. Prefer [REMOTE/LOCATIONS]. Minimum compensation: [MINIMUM], when disclosed. Skip roles requiring relocation outside my preferences unless remote.

MATCHING
Score every role 0–100 for relevant experience, required skills, seniority, domain, location, compensation, and work-authorization compatibility. Continue only at [SCORE THRESHOLD]+. Never invent experience, credentials, education, achievements, technologies, metrics, identity, immigration details, or legal answers.

MATERIALS
Treat my attached master résumé as the source of truth and my template as the formatting reference. Tailor only when it materially improves fit; preserve its headings and ATS-friendly structure. Reuse a strong existing version when it already fits. Record which résumé version is used.

WORKFLOW
1. Find and deduplicate roles from approved job sources and official employer ATS pages.
2. Return a tracker row for each evaluated role: company, title, location, source, fit score, decision, key reasons, résumé version, and next action.
3. For qualified roles, prepare tailored materials and prefill only fields supported by my private profile.
4. Mark NEEDS REVIEW rather than guessing when required information is missing or uncertain.
5. Stop and request review for CAPTCHA, MFA, password/account creation, legal attestations, voluntary self-identification, sensitive-data entry, or final submission.
6. Use connected Gmail only to find application confirmations, verification notices, assessments, recruiter messages, interviews, rejections, and status updates. Do not delete or send email unless I explicitly ask.
7. Keep statuses limited to: APPLIED, NEEDS REVIEW, SKIPPED, DUPLICATE, APPLICATION FAILED, ACCOUNT/LOGIN REQUIRED, CLOSED.

OUTPUT EACH RUN
Give me: jobs evaluated, jobs meeting threshold, applications prepared, applications submitted only with my explicit confirmation, blocked items, Gmail follow-ups, and the updated tracker. Prioritize high-quality, accurate work over volume.

What to personalize privately

Add your own target roles, locations, salary floor, work authorization/sponsorship facts, contact details, and résumé files in the private chat—not in this public prompt.
